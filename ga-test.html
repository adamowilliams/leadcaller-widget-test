Så bevisar du hela kedjan

  1. Slå på sendGtm: admin → widgeten → flik Spårning → Google Tag Manager → Aktiv.
  2. Avkommentera GTM-blocket överst + byt GTM-XXXXXXX mot ditt container-id.
  3. I GTM: Custom Event-trigger leadcaller_chat_started → GA4 Event-tag mot din property. Publicera.
  4. Öppna som ?utm_source=google, starta en chatt → gul rad dyker upp här direkt.
  5. GA4 → DebugView visar leadcaller_chat_started. Exploration → bryt på Session source → Google vs. annat.
